    Section 1.1 Real Numbers

    Question 1.1.1.

    What is a "number"?
    🔗
    🔗

    Observation 1.1.2.

    Things we think of as "numbers" seem to have the following properties:
    🔗

    Aside
    In particular, these operations should both be commutative and associative, and obey distributive rules.
    🔗
    1. There are operations \(+\) and \(\times\) that behave as we expect.
      🔗
    2. There are identity elements: \(0\) for addition and \(1\) for multiplication.
      🔗
    3. These operations have inverse operations \(-\) and \(\div\text{,}\) respectively.
      🔗
    4. Every number has an additive inverse and every non-zero number has a multiplicative inverse.
      🔗
    Mathematicians call anything with these properties a field.
    🔗
    🔗

    Example 1.1.3.

    The set of rational numbers, denoted \(\Q\text{,}\) is a field.
    🔗
    🔗

    Example 1.1.4.

    The set of constructible numbers are the lengths that can be constructed with a compass and straight edge, given a line segment of length \(1\text{.}\) The number \(\sqrt{2}\) is constructible, but \(\sqrt[3]{2}\) is not.
    🔗

    Aside
    A classical geometry question asks if, given a cube, another cube of twice the volume can be constructed with a compass and a straight edge. Showing that this is impossible is equivalent to showing that \(\sqrt[3]{2}\) is not constructible and took over 2000 years to solve.
    🔗
    The set of constructible numbers also forms a field.
    🔗
    🔗

    Example 1.1.5.

    The set of rational functions, i.e. functions of the form \(\dfrac{p(x)}{q(x)}\text{,}\) where \(p(x)\) and \(q(x)\) are polynomials, is a field.
    🔗
    🔗

    Observation 1.1.6.

    The rational numbers (and the constructible numbers) are an ordered field: we have an inequality operator \(\lt\) such that for any two distinct rational numbers \(a\) and \(b\text{,}\) either \(a\lt b\) or \(b \lt a\text{.}\)
    🔗
    🔗

    Activity 1.1.7.

    Consider the set of numbers
    \begin{equation*} E=\{x \in \Q\ \mid\ x^2 \lt 2 \}\text{.} \end{equation*}
    🔗

    Aside
    This an example of what we call set builder notation. The curly braces \(\{\) and \(\}\) denote a set, and \(\in\) means "is an element of" or "in", and \(\mid\) means "such that". This whole set \(E\) is then "The set of all \(x\) that are elements of \(\Q\) such that \(x^2 \lt 2\)"
    🔗

    (a)

    Find a rational number \(a \in \Q\) that is an upper bound for \(E\text{;}\) that is, \(a \gt x\) for every \(x \in E\text{.}\)
    🔗
    🔗

    (b)

    What is the smallest rational number \(a \in \Q\) that is an upper bound for \(E\text{?}\)
    🔗
    🔗
    🔗

    Definition 1.1.8.

    An ordered set \(S\) has the least-upper-bound property if every nonempty subset \(E \subset S\) that has an upper bound has a least upper bound.
    🔗
    An ordered field that has the least-upper-bound property is called complete.
    🔗
    🔗

    Example 1.1.9.

    The rational numbers \(\Q\) does not have the least upper bound property as we saw in Activity 1.1.7. In other words, \(\Q\) is not complete.
    🔗
    🔗

    Theorem 1.1.10.

    There is a unique complete ordered field that contains the rational numbers.
    🔗
    🔗

    Remark 1.1.11.

    Note that this theorem is saying two things: there exist complete ordered fields that contain the rationals, and further any two such fields are actually the same (i.e. it is unique).
    🔗
    🔗

    Definition 1.1.12.

    The real numbers, denoted \(\R\text{,}\) are the unique complete ordered field containing \(\Q\text{.}\)
    🔗
    🔗

    Remark 1.1.13.

    You can think about "building" \(\R\) from \(\Q\) by formally adding least upper bounds to every subset of \(\Q\text{.}\)
    🔗
