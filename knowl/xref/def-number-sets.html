Definition A.1.1.

We will work with a number of sets in this class. Common sets are
  • \(\N=\{1,2,3,\ldots\}\text{,}\) the set of natural numbers.
    🔗
  • \(\Z=\{\ldots,-3,-2,-1,0,1,2,3,\ldots\}\text{,}\) the set of integers.
    🔗
  • \(\Q\text{,}\) the set of rational numbers.
    🔗
  • \(\R\text{,}\) the set of real numbers defined in Section 1.1.
    🔗
