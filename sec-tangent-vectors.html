    Section 2.2 Tangent Vectors

    Given a curve \(\vec{r}(t)\text{,}\) we can plot a secant vector by computing \(\vec{r}(t+h)-\vec{r}(t)\) for some real number \(h\text{.}\) Intuitively, we might consider constructing a tangent vector through some sort of limiting process as \(h \rightarrow 0\text{.}\)
    🔗
    Recall the definition of a limit from single variable calculus:
    🔗

    Definition 2.2.2.

    Let \(f(x)\) be a real-valued function defined on an open interval near a point \(a\) (except possibly at \(a\)). Then we say that \(\displaystyle \lim _{x \rightarrow a} f(x)=L\) if for every \(\epsilon \gt 0\text{,}\) there exists \(\delta \gt 0\) such that
    \begin{equation*} |f(x)-L| \lt \epsilon \text{ whenever } |x-a| \lt \delta\text{.} \end{equation*}
    🔗
    🔗
    In other words, \(\displaystyle \lim _{x \rightarrow a}f(x)=L\) means that for every choice of \(\epsilon \gt 0\text{,}\) we can ensure that \(f(x)\) is within \(\epsilon\) of \(L\) by choosing a sufficiently small interval around \(a\text{.}\)
    🔗
    To adapt this to vector valued functions, we simply need to make precise what it means to be “within \(\epsilon\) of a vector”.
    🔗

    Definition 2.2.3.

    Let \(\vec{L} \in \R^n\text{,}\) and let \(\epsilon \gt 0\text{.}\) Then we set
    \begin{equation*} B_{\epsilon}(\vec{L}) = \left\{ \vec{x} \in \R^n \ \middle| \ |\vec{x}-\vec{L}| \lt \epsilon \right\}\text{,} \end{equation*}
    i.e. so that \(B_\epsilon (\vec{L})\) is the set of all points in \(\R^n\) that are within \(\epsilon\) of the point \(\vec{L}\text{.}\)
    🔗
    🔗

    Definition 2.2.4.

    Let \(\vec{r}(t)\) be a vector-valued function defined on an open interval near a point \(a\) (except possibly at \(a\)). Then we say that \(\displaystyle \lim _{t \rightarrow a} \vec{r}(t)=\vec{L}\) if for every \(\epsilon \gt 0\text{,}\) there exists \(\delta \gt 0\) such that
    \begin{equation*} \vec{r}(t) \in B_\epsilon(\vec{L}) \text{ whenever } |t-a| \lt \delta\text{.} \end{equation*}
    🔗
    🔗
    While conceptually nice, this definition is difficult to work with in practice. Fortunately, we are able to leverage what we know about single variable limits.
    🔗

    Proposition 2.2.5.

    Let \(\vec{r}(t)=\langle x(t),y(t),z(t)\rangle \) be a vector valued function. Then
    \begin{equation*} \lim _{t \rightarrow a} \vec{r}(t) = \left \langle \lim _{t \rightarrow a} x(t), \lim _{t \rightarrow a} y(t), \lim _{t \rightarrow a} z(t) \right \rangle \end{equation*}
    when all of these limits exist.
    🔗
    🔗
    With this in hand, we can now return to our idea of a tangent vector.
    🔗

    Definition 2.2.6.

    Let \(\vec{r}(t)\) be a vector-valued function. The tangent vector to \(\vec{r}(t)\) is the limit
    \begin{equation*} \vec{r}^\prime(t) = \lim _{h \rightarrow 0} \frac{\vec{r}(t+h)-\vec{r}(t)}{h}\text{.} \end{equation*}
    🔗
    When \(\vec{r}(t)\) represents the position of an object, the tangent vector \(\vec{r}^\prime(t)\) is also called the velocity (vector). Its magnitude, \(|\vec{r}^\prime(t)|\) is called speed.
    🔗
    🔗
    An immediate consequence of Proposition 2.2.5 is
    🔗

    Proposition 2.2.7.

    If \(\vec{r}(t)=\langle x(t), y(t), z(t)\rangle\text{,}\) then
    \begin{equation*} \vec{r}^\prime(t) = \langle x^\prime(t), y^\prime(t), z^\prime(t) \rangle\text{.} \end{equation*}
    🔗
    🔗

    Activity 2.2.8.

    🔗

    (a)

    \(\vec{r}_1(t)= \langle \cos(t), \sin(t) \rangle\)
    🔗

    (b)

    🔗
    Because derivatives can be computed component-wise, our usual derivative rules translate to the vector context in a straightforward way.
    🔗

    Fact 2.2.9.

    Let \(f\) be a differentiable real-valued function of a real variable \(t\text{.}\) Let \(\vec{r}\) and \(\vec{s}\) be differentiable vector-valued functions of the real variable \(t\text{.}\) Then
    Sum Rule
    🔗
    \(\displaystyle \frac{d}{dt} \left[\vec{r}(t) + \vec{s}(t) \right] = \vec{r}\, '(t) + \vec{s}\, '(t)\)
    🔗
    Scalar Multiplication Product Rule
    🔗
    \(\displaystyle \frac{d}{dt} \left[f(t) \vec{r}(t)\right] = f(t) \vec{r}\, '(t) + f'(t) \vec{r}(t)\)
    🔗
    Dot Product Rule
    🔗
    \(\displaystyle \frac{d}{dt} \left[\vec{r}(t) \cdot \vec{s}(t) \right] = \vec{r}\, '(t) \cdot \vec{s}(t) + \vec{r}(t) \cdot \vec{s}\, '(t)\)
    🔗
    Cross Product Rule
    🔗
    \(\displaystyle \frac{d}{dt} \left[\vec{r}(t) \times \vec{s}(t) \right] = \vec{r}\, '(t) \times \vec{s}(t) + \vec{r}(t) \times \vec{s}\, '(t)\)
    🔗
    Chain Rule
    🔗
    \(\displaystyle \frac{d}{dt} \left[\vec{r}\left(f(t)\right)\right] = f'(t) \ \vec{r}\, '(f(t))\)
